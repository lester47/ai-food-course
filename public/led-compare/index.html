X → 0　1　2　3　4
請點一顆 LED
Y 從上往下：0 → 4

座標口訣：先看 X（左右），再看 Y（上下）。例如 (2,1) 是第 3 欄、第 2 列。

15–27 分鐘｜第二站
🌈 WS2812 的 10 顆彩色 LED
這次不用 X、Y 座標，而是從 0 到 9 依序替 LED 編號。每顆燈都可以自己選顏色！
點擊任意燈泡，指定它的顏色
目前選擇：第 0 顆燈
DIN → 訊號由編號 0 開始
RGB 彩色實驗室
紅 R、綠 G、藍 B 都能設定 0～255。移動滑桿，看看你混合出什麼顏色。
接線提醒：燈條三條線插在 robot:bit 的 P0 排針：黑線 G、紅線 V、黃線 S，從燈條箭頭開始的那一端（DIN）接入。先拔掉 robot:bit 的蜂鳴器跳線帽，蜂鳴器也接在 P0，不拔的話燈會亂閃、還會吱吱叫。記得打開 robot:bit 電源，亮度先設 40，避免耗電過大。

30–35 分鐘｜動手實作
🎮 A、B、A+B 三鍵燈光挑戰
延續上一堂課的按鈕能力，這次讓學生自己改寫三段事件積木。小技巧：「顯示圖示」會停約 0.6 秒，所以先換燈條顏色、再顯示圖示，兩種燈才會幾乎同時改變。
任務卡
按鈕25 顆矩陣10 顆彩燈
A笑臉全綠
B愛心全紅
A+B清除全熄
上方按鈕可以直接控制這個網頁的兩個 LED 模擬器。
完整範例程式
可直接複製到 MakeCode JavaScript
let strip = neopixel.create(DigitalPin.P0, 10, NeoPixelMode.RGB)
strip.setBrightness(40)
strip.clear()
strip.show()
input.onButtonPressed(Button.A, function () {
    strip.showColor(neopixel.colors(NeoPixelColors.Green))
    basic.showIcon(IconNames.Happy)
})
input.onButtonPressed(Button.B, function () {
    strip.showColor(neopixel.colors(NeoPixelColors.Red))
    basic.showIcon(IconNames.Heart)
})
input.onButtonPressed(Button.AB, function () {
    basic.clearScreen()
    strip.clear()
    strip.show()
})
🐞 找錯誤：哪裡有問題？（先讓學生說）
strip.setPixelColor(10, neopixel.colors(NeoPixelColors.Red))
strip.show()
這裡希望控制「第 10 顆」燈，但燈條只有 10 顆，編號是 0～9。
把 10 改成 9。也要先建立 strip，這段程式才有控制對象。
⭐ 進階挑戰（提早完成者）
把 A 改成全藍、B 改成彩虹；試著讓 (0,0) 和編號 0 同時亮起。想想：可以讓 10 顆燈代表 10 步跑步進度嗎？
