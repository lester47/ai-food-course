# 學生操作指南

1. 在首頁按「開始第一週」。先看本關目標，再照步驟操作官方 MakeCode。
2. 用模擬器測試，結果不同時展開除錯提示。第一週不必接 USB。
3. 到互動實驗室按 A、B，觀察步數與 LED。模擬器不是已連接的硬體。
4. 完成後勾選「我完成這一關了」，再按下一關。這只是本機紀錄，換電腦或清除瀏覽器資料可能不見。
5. 每週結束到本週作業頁，準備作品連結、截圖／影片及心得。
6. 老師開放後，按「前往表單填寫」，在 Google 表單內完成送出。請以表單確認及老師回應為準。

不要公開姓名、學號、私人照片或密碼。有問題先記下「我做了什麼、預期看到什麼、實際看到什麼」，再請老師協助。

第二週起的 USB 練習要用 Chrome／Edge 桌機與可傳資料的線。使用者必須親自點連接、選裝置、授權；不能連線時仍可用手動示範模式。
