# 示範資料

此資料僅供本機互動測試，不含真實學生或繳交記錄。

單人輸入：STEP,0 → STEP,3 → STEP,10 → RESET。

雙隊輸入：R,3 → G,5 → R,3（仍是 3，不重複累加）→ R,10 → RESET。

錯誤輸入：G,abc、R,-1、G,1.5、X,3，應拒絕並顯示繁體中文說明。

LED：紅隊 3、綠隊 6 時，上兩排共三燈、下兩排共六燈，第三排全暗。

領地：整合挑戰送 R,10，選南投市，按達標攻佔，紅隊一區且步數歸零。再使用 RESET 開始新回合（RESET 保留領地；重置全部領地會清空領地、步數與答題）。
