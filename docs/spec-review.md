# 開發規格檢視與本期決策

規格 v1.0 的順序清楚：第一週程式基礎、第二週連線、第三週資料分流、第四週地理、第五週整合。靜態網站加外部 Google 表單適合作為不收集兒童個資的 MVP。

## 需要釐清的相依條件

- 第 7.1 節提及教師回應試算表設定，但第 12 節禁止公開私人管理網址。本版採第 12 節較保護隱私的做法：公開設定僅放學生填答網址，教師自行從 Google 表單管理後台開啟回應。
- 第 4、15 節允許缺可信截圖時標示待補。因此本版交付文字教學及截圖欄位，不生成仿積木。
- 第 4 週正式行政地圖依賴未提供的既有穩定版／GeoJSON。本版採規格允許的卡片初學練習，保留既有遊戲網址擴充點；正式地圖仍待補。
- 第 2～5 週原規格沒有細分分鐘，本版每週六關各 30 分鐘，共 180 分鐘。
- 真實交件需要教師建立表單與授權。沒有帳號、表單或學生測試身分時，不能宣稱已驗證實際交件。
- 原生上傳、教師角色與私人批閱另需後端，本期不偽裝成已完成。

## 專案盤點

指定的「假日班-南投食農大使」目錄原先僅有規格書。當前聊天工作區只有 Git 目錄，沒有既有網頁、框架、可重用資料或遠端設定。因此在規格書旁新增獨立 ai-food-course，使用無套件的原生 ES modules，沒有改寫任何穩定版。

本次未推送正式分支、未公開部署。dist 可獨立部署到 GitHub Pages；hash 路由支援儲存庫子目錄及重新整理。
