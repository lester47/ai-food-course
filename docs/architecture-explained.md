# AI 食農大使專題架構解說

## 1. 學生如何輸入？

第一週先在官方 MakeCode 編輯器裡學事件、變數、條件與 LED，使用瀏覽器模擬器即可。網站中的示範按鍵讓學生觀察相同概念；網站並未直接控制 MakeCode 模擬器。

第二週起可以把程式下載到實體 micro:bit，按鍵改變累積步數，再以 USB 序列逐行送出 STEP,3、R,3、G,5 或 RESET。網站用 Web Serial 讀取；需要 Chrome／Edge 桌機、安全環境與使用者親自授權。第一週不必接 USB。

## 2. 網站如何處理？

網站是可放在 GitHub Pages 的靜態 HTML、CSS、JavaScript。課程資料和畫面分開，教師能修改五週與任務內容。

接收到文字後，先驗證標籤與數值，再更新步數及進度條；錯誤資料會拒絕。雙隊 LED 上兩排代表紅隊、下兩排代表綠隊，中央排固定留白；實體 LED 是單色。

第四、五週先以 13 鄉鎮卡片練習選取、領地與分數；整合模式每隊到 10 步才能攻佔。正式行政地圖必須另行整合教師提供的真實界線或既有穩定版，不可把卡片當成行政地圖。

## 3. 作品如何交給老師？

老師先建立真實 Google 表單並填入公開設定。學生從網站前往表單，填寫作品連結、心得和測試紀錄，在 Google 表單內送出。沒有設定時，網站顯示「尚未開放繳交」。

老師從 Google 表單回應或私人試算表確認作品，再用學校核准的私人管道回饋。網站不讀取私人回應、不知道表單是否已送出，也不提供站內檔案儲存或私人批閱。

## 4. 兩種「紀錄」要分清楚

「我完成這一關了」存在此瀏覽器的 localStorage，只是學生自我檢核。真正交件紀錄在 Google 表單回應。兩者不會自動同步，不能互相替代。

## 5. 圖中的實線與虛線

實線表示本版已有的學習與資料傳送流程；真實表單需教師設定、USB 程式仍需實體板子驗收。虛線表示由外部管道進行的私人回饋或尚待補充的素材。真實積木截圖、已核對農產、授權圖片與行政界線仍待教師準備。
