# 整體專案模組拆解

此文件先依開發規格與現有程式拆解責任，再作為總架構圖的依據。這是功能模組，不代表已拆成多個服務；目前多數畫面與互動仍集中在 app.js。

| 模組 | 子功能與責任 | 輸入 → 輸出 | 對應程式與狀態 |
| --- | --- | --- | --- |
| 使用者與入口 | 學生、教師、訪客的操作流程 | 使用者操作 → 課程／作業／展示 | app.js、index.html；無登入或角色權限 |
| 五週教材 | 週次、任務、概念、步驟、測試、除錯、作業 | 教師編修資料 → 課程與任務頁 | data/weeks.js、data/tasks.js；34 任務，截圖待補 |
| 網站與進度 | hash 路由、導覽、教材呈現、授權作品、本機完成勾選 | 路由＋教材 → 頁面；勾選 → localStorage | app.js、styles.css；無跨裝置同步 |
| 硬體通訊 | 手動授權、連接、讀取、分行、驗證、斷線處理 | micro:bit → USB → Web Serial → 有效步數狀態 | services/serial.js、services/core.js；程式已實作，硬體待驗收 |
| 食農遊戲 | LED／進度、雙隊競跑、鄉鎮、領地、分數、題目 | 步數＋選取＋作答 → 進度／領地／回饋 | app.js 的 practice、townPanel、quiz；卡片已實作，正式地圖與食農圖文待補 |
| 作業與教師回饋 | 每週要求、表單入口、回應確認、私人回饋 | 作品連結 → Google 表單 → 私人回應／教師 | config/assignments.js、core.js 的 formLink、app.js；需設定真實表單 |
| 資料與部署 | 公開設定、素材、外部遊戲入口、建置、預覽與發布 | 原始碼／資料 → dist → HTTPS 靜態主機 | scripts/build.mjs、scripts/serve.mjs、public；本機已執行，未公開部署 |

## 模組間的四條主要關係

1. 教學：教材資料 → 課程網站 → 學生依五週順序學習與練習。
2. 互動：micro:bit／手動輸入 → 資料驗證 → 步數與雙隊進度 → 食農領地互動。
3. 交件：網站作業說明 → 外部 Google 表單 → 教師私人回應資料 → 校內核准的私人回饋管道。
4. 維護：教師修改內容與公開設定 → 測試／build → 靜態部署 → 使用者瀏覽。

## 五週課程與模組的對應

- 第一週：教材＋網站＋手動 LED／計步模擬，不需要 USB。
- 第二週：加入硬體通訊與單人步數解析。
- 第三週：加入 R／G 分流與雙隊進度、達標、重置。
- 第四週：加入鄉鎮資料、來源查核與地圖學習；目前實作卡片，正式界線待整合。AI 協助修改網頁是教學活動，不是本站內建 AI 服務。
- 第五週：整合硬體／手動輸入、雙隊進度、食農領地與知識題，再完成作品展示與真實交件。

## 總圖如何呈現

七個責任模組整合為四個視覺層：使用者層、網站與五週課程層、資料與外部服務層、部署與版本界線層。不能把課程順序誤畫成只有第一週，也不能將外部私人回應資料畫進公開網站。

圖中會區分實作與相依條件：表單需教師開通；硬體需實體驗收；正式地圖、核對農產、授權素材與真實積木截圖仍待提供。沒有站內登入、原生檔案上傳或私人批閱後台。
