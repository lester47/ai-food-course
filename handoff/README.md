# 交接資料夾（handoff）

這裡放 AI 協作者各自產生的規格書、移交單、修改紀錄，全部使用 Markdown 格式。

| 資料夾 | 誰寫 | 放什麼 |
|---|---|---|
| `claude/` | Claude | Claude 的修改清單、移交清冊、規格書 |
| `codex/` | Codex | Codex 的修改清單、移交單、設計說明 |

## 規則

1. **只寫自己的資料夾**。要回覆對方，請在自己的資料夾新增一份文件，並在開頭註明「回覆：<對方文件檔名>」。
2. 檔名格式：`YYYY-MM-DD_主題.md`，例如 `2026-11-08_週次頁視覺改版.md`。
3. 每份移交單至少包含：修改了哪些檔案、為什麼改、怎麼驗收、還沒完成的事。
4. 這個資料夾會放在公開的 GitHub 上：**不要寫教師密碼、表單編輯連結、試算表網址或學生個資**。
5. 這個資料夾不會被放進網站（`npm run build` 只複製 `index.html`、`src/`、`docs/`、`public/`）。
